# Les citations de référence · édition Belin

*Le Contr’un* · document de travail · version 0.2 du 24 novembre 2026

**L’édition Belin fournie par Lucas est la référence unique du projet.** C’est une traduction en français moderne, établie sur le manuscrit de Mesmes. Ses formulations diffèrent souvent de celles de l’Atelier La Boétie, que le jeu utilisait jusqu’ici.

**Méthode.** Le texte des pages 8 à 40 du PDF a été passé à la reconnaissance de texte pour repérer les passages. Chaque citation ci-dessous a ensuite été **relue sur l’image de la page**, mot à mot, ponctuation comprise. Les références donnent la **page du livre** et les **numéros de ligne** de la marge, relevés à une ou deux lignes près : à recontrôler pour les fiches distribuées aux élèves.

Conventions : les crochets […] signalent une coupe ; la minuscule initiale est conservée quand la citation commence en milieu de phrase ; aucune citation n’est reformulée.

## 2. La passe de pertinence

Chaque citation est notée selon trois critères :

- **son poids pour l’EAF** : passage d’explication linéaire de l’édition Belin, ou idée centrale de l’œuvre ;
- **sa force dans le jeu** : une situation, un personnage, une image qu’elle peut porter ;
- **sa lisibilité** pour un élève de seize ans, sans note de bas de page.

Trois niveaux en découlent :
- ★★★ **Pivot** : un feuillet, une scène clé ou une joute. L’élève doit la retenir.
- ★★ **Appui** : une réplique, une planche, un carnet, une séquence illustrée.
- ★ **Réserve** : utile pour le professeur ou une fiche, mais trop longue, trop allusive ou délicate dans le jeu.

**Les trois explications linéaires de l’édition Belin** (repères imprimés dans le livre) :
1. « Pauvres et misérables peuples insensés… » (p. 25, renvoi p. 84) ;
2. « Il y a trois sortes de tyrans… » (p. 34, renvoi p. 88) ;
3. « C’est certainement que le tyran n’est jamais aimé, ni n’aime… » (p. 71, renvoi p. 90).

Ce sont vraisemblablement les passages étudiés en classe. Les trois reçoivent une place forte dans le jeu.
